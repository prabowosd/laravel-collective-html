Install

composer require prabowosd/laravel-collective-html

The service provider and the Form and Html facade aliases register themselves through package discovery. Nothing to add to config/app.php.

The package declares replace for laravelcollective/html 6.x. If another dependency in your tree still asks for the original, Composer resolves it to this package instead of installing both, so the Collective\Html classes are only ever defined once.

Migrate from laravelcollective/html

The namespace, class names, facades and helpers are the ones you already import. Your views do not change.

  1. Remove the original packageIt is abandoned and does not install on Laravel 11 or newer. 
    composer remove laravelcollective/html
  2. Require the revived oneSame Collective\Html classes, same rendered HTML. 
    composer require prabowosd/laravel-collective-html
  3. Clear compiled viewsBlade directives such as @form_text are compiled into cached views. 
    php artisan view:clear

If you subclass FormBuilder or HtmlBuilder, check your overrides: most methods now declare native return types such as HtmlString, and an override must declare a compatible one.

Opening forms

Form::open() takes the target as url, route or action. Methods other than GET and POST are spoofed with a hidden _method field, and every non-GET form gets the CSRF token.

Blade

{!! Form::open([
    'url' => 'profile',
    'method' => 'PUT',
    'files' => true,
]) !!}

Renders

<form method="POST" action="https://example.com/profile" accept-charset="UTF-8" enctype="multipart/form-data">
<input name="_method" type="hidden" value="PUT">
<input name="_token" type="hidden" value="…">
{!! Form::open(['route' => ['users.update', $user]]) !!}
{!! Form::open(['action' => [UserController::class, 'store']]) !!}

// Model binding: a field with no explicit value is filled from the model
{!! Form::model($user, ['route' => ['users.update', $user], 'method' => 'PATCH']) !!}

{!! Form::close() !!}

Fields

Every field resolves its value in the same order: old input from the session, then the value you pass, then the bound model. A field gets an id automatically when a Form::label() with the same name was rendered before it.

Blade

{!! Form::text('username', 'sdp', [
    'placeholder' => 'Username',
]) !!}

Renders

<input placeholder="Username" name="username" type="text" value="sdp">
MethodSignature
text, email, tel, number, url, search, range, color, hidden($name, $value = null, $options = [])
date, time, datetime, datetimeLocal, month, weekSame, and a DateTimeInterface value is formatted for the input type
password, file($name, $options = []), never filled
textarea($name, $value = null, $options = []), 'size' => '50x10' sets cols and rows
checkbox($name, $value = 1, $checked = null, $options = [])
radio($name, $value = null, $checked = null, $options = []), value defaults to the name
label($name, $value = null, $options = [], $escape_html = true)
submit, button, reset($value = null, $options = [])
image($url, $name = null, $attributes = [])
input($type, $name, $value = null, $options = []) for any other type

Boolean attributes are written as numeric keys: ['required', 'autofocus'] renders required autofocus.

Selects

Blade

{!! Form::select('size', [
    'L' => 'Large',
    'S' => 'Small',
], 'S') !!}

Renders

<select name="size">
  <option value="L">Large</option>
  <option value="S" selected="selected">Small</option>
</select>

Nested arrays become <optgroup>s. Pass an array as the selected value for a multiple select, and 'placeholder' => 'Pick one' for an empty first option.

{!! Form::selectRange('qty', 1, 10) !!}
{!! Form::selectYear('year', 2020, 2030) !!}
{!! Form::selectMonth('month') !!}   // month names in the app locale

From an enum

Backed enums use their value, pure enums the case name. A label() method on the enum supplies the option text, otherwise the case name is humanized.

Blade

{!! Form::enumSelect(
    'status',
    OrderStatus::class,
    'shipped',
) !!}

Renders

<select name="status">
  <option value="pending">Pending</option>
  <option value="shipped" selected="selected">Shipped</option>
</select>

From Eloquent

The source can be a model class, a query or relation, a collection, or a plain array of rows.

{!! Form::modelSelect('category_id', Category::class, 'name', 'id', $selected) !!}
{!! Form::modelSelect('owner_id', $team->members(), 'full_name') !!}

Validation

These read the $errors bag Laravel shares with every view. Array names map to dot keys, so person[name] checks person.name. Classic calls are untouched: the invalid class is only added where you ask for it.

Blade

{!! Form::text('email', null,
    Form::withValidationClass('email', [
        'class' => 'form-control',
    ])
) !!}
{!! Form::error('email') !!}

Renders, with an error

<input class="form-control is-invalid" name="email" type="text">
<div class="invalid-feedback">The email field is required.</div>
@if (Form::hasError('email')) ... @endif
{{ Form::getError('email') }}   // first message, or null

Form::error() returns an empty string when the field is valid, so it is safe after every control.

Blade components

Label, control and error feedback in one tag. Any attribute that is not a prop (placeholder, class, data-*) lands on the control.

<x-form-input name="email" label="Email" type="email" placeholder="you@example.com" />
<x-form-input name="bio" label="Bio" type="textarea" rows="4" />

<x-form-select name="role" label="Role" :options="['admin' => 'Admin', 'member' => 'Member']" selected="member" />
<x-form-select name="status" label="Status" :enum="App\Enums\OrderStatus::class" />
<x-form-select name="category_id" label="Category" :model="App\Models\Category::class" label-column="name" />

<x-form-checkbox name="agree" label="I accept the terms" :checked="true" />

Html builder

Assets, links and small markup helpers. URLs go through Laravel's URL generator.

Blade

{!! Html::link('docs', 'Read the docs', [
    'class' => 'btn',
]) !!}

Renders

<a href="https://example.com/docs" class="btn">Read the docs</a>
MethodOutput
script, style, favicon, image<script>, <link> and <img> tags for an asset path
link, secureLink, linkAsset, linkRoute, linkActionAnchors to a URL, asset, named route or controller action
mailto, email, obfuscateEntity-obfuscated addresses
ul, ol, dlLists from arrays, nested arrays nest
meta, tagAny element with attributes
entities, decode, nbspEscaping helpers

The global helpers link_to(), link_to_asset(), link_to_route() and link_to_action() are still there, each guarded so it never clashes with a function you define yourself.

Configuration

Classes used by the validation helpers and components default to Bootstrap. Publish the config to map them to Tailwind or anything else.

php artisan vendor:publish --tag=html-config
// config/html.php
'classes' => [
    'control' => 'form-control',
    'select' => 'form-select',
    'label' => 'form-label',
    'invalid' => 'is-invalid',
    'feedback' => 'invalid-feedback',
    'check_wrapper' => 'form-check',
    'check_input' => 'form-check-input',
    'check_label' => 'form-check-label',
],
